# Contribuer

- Toute modification passe par une pull request ; `main` est protégée.
- Une PR fait une chose. Son titre dit ce qu'elle change.
- Aucun secret dans le code, l'historique, les tickets ou les journaux : la CI cherche dans tout l'historique (`secrets.yml`).
- Le code écrit avec un assistant (Claude, Codex) suit `AGENTS.md` du dépôt et est relu par un humain avant fusion.
