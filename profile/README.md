# xSOM Consulting

Cabinet de conseil. Sa division IA conçoit des outils pour utiliser les assistants de code en entreprise sans exposer de secrets.

- **[xSOM Fleet](https://fleet.xsom.fr)** : la plateforme. Abonnements d'assistants de code à l'échelle de l'entreprise, Contrôle avant envoi sur chaque Poste, coût réel par Développeur, preuves pour l'audit.
- **[Secret Guard](https://guard.xsom.fr)** ([code](https://github.com/xsom-consulting/secret-guard), Apache-2.0) : le moteur de détection de secrets, ouvert. Il s'exécute sur le poste, sans réseau ni modèle de langage.

Site : [xsom.fr](https://www.xsom.fr) · Division IA : [ai.xsom.fr](https://ai.xsom.fr)

A consulting firm. Its AI division builds tools to use coding assistants at company scale without leaking secrets: **xSOM Fleet**, the platform, and **Secret Guard**, the open source secret detection engine that runs on the workstation.
